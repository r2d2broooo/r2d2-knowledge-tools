# r2d2-knowledge-tools

Deterministic document-to-skill extraction, markdown wiki management and Python code graph utilities.

Build compact reusable knowledge from documents and inspect source relationships without a trading service.

## Features

- PDF, text, HTML, EPUB and DOCX extraction
- Per-chapter document output
- Markdown wiki tools
- Deterministic Python AST graph

## Use

python3 check.py; python3 book-to-skill/scripts/extract.py --check; python3 wiki/wiki.py --help.

Run `python3 check.py` for read-only source checks. These checks are not a claim
that external accounts, market feeds, hardware or a deployed service are configured.
